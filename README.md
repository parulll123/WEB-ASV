# 🚤 ASV Monitoring Website – 2025

Ini adalah proyek pengembangan website **sederhana berbasis Flask** yang dirancang untuk mendukung sistem **monitoring ASV (Autonomous Surface Vehicle)** tahun 2025. Website ini menyajikan data sensor dan informasi geospasial secara **real-time**, dengan antarmuka web yang ringan dan responsif.

---

## 📌 Fitur Utama

- 🌐 Antarmuka berbasis Flask + HTML/CSS/JS
- 📡 Realtime monitoring posisi ASV (GPS)
- 📊 Visualisasi data sensor (Chart.js atau sejenis)
- 📥 Komunikasi dengan perangkat (ESP32, Raspberry Pi, atau mikrokontroler lain)
- 📁 Struktur proyek yang rapi dan mudah dikembangkan

---

## 🛠️ Teknologi yang Digunakan

| Komponen         | Deskripsi                          |
|------------------|-------------------------------------|
| Python 3.x       | Bahasa pemrograman utama            |
| Flask            | Framework web ringan (backend)      |
| HTML5 + CSS3     | Antarmuka pengguna                  |
| JavaScript       | Interaktivitas & fetch data         |
| Chart.js         | Visualisasi grafik                  |
| Bootstrap (opsional) | Desain responsif                 |

---

## 🚀 Cara Menjalankan Proyek

1. **Clone repository ini**
git clone https://github.com/parull123/WEB-ASV

2. Buat venv untuk library python
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

3. Install dependency
pip install -r requirements.txt

4. Jalankan server
python app.py
